## 🌟 系統特色與 HCI 設計亮點

本原型嚴格落實【作業一】規格書所規劃之全套功能與理論依據：

1. **雙模態人機互動視圖切換**：
   - 📱 **借款人行動前台 (Mobile Borrower App)**：擬真智慧型手機外框（支援全螢幕展開切換），提供 7 步驟直覺申貸流程。
   - 💻 **案件審核桌面後台 (Desktop Admin Portal)**：授信審查專員（陳專員）工作台，整合 12 案批次統計、審查工作清單、實質決策理由強制填寫與稽核操作日誌。
   - 📖 **研究規格與理論對照抽屜**：隨時開啟查閱 2026 雙北中低收入所得參照基準、Persona 人物誌、Amershi et al. (2019)、Horvitz (1999)、Černevičienė (2024) 與 Maathuis et al. (2026) 等理論依據。

2. **核心決策與金融計算引擎**：
   - **10 萬元核貸分流機制**：申請金額 $\le 100,000$ 元由 AI 決策引擎直接判定；$> 100,000$ 元分流至人工專員實質審核，標記「人工審核中，尚未核准」（解決 SIM-W03 誤認已核准之痛點）。
   - **40% 安全現金流保護規則**：可用餘額 $R = I - E - D$（收入 - 必要支出 - 既有債務），新貸款月付額 $\le 0.40 \times R$，保留生活緊急緩衝金。
   - **三種還款方案透明比較**（依 50,000 元、固定年利率 6%）：
     - **方案 A（6期）**：月付 8,480 元，總額 50,879 元，利息 879 元（標示「超出上限」，利息最低）。
     - **方案 B（12期）**：月付 4,303 元，總額 51,640 元，利息 1,640 元（標示「超出上限」）。
     - **方案 C（18期）**：月付 2,912 元，總額 52,409 元，利息 2,409 元（唯一「符合負擔上限」，可選）。
     - **使用者掌控權保證**：絕不預選最長期方案，無倒數計時心理施壓，清楚呈現月付與總利息成本差額（解決 SIM-I02 痛點）。

3. **錯誤復原與人類接管 (Mixed-Initiative & XAI)**：
   - **收入誤讀更正 (SIM-W02)**：提供明確的「更正資料」按鈕，並列原值（18,000元）與新值（28,000元），即時重新試算。
   - **人工覆核申訴管道 (SIM-I04 / ML004)**：審核不通過時，提供可見之人工覆核入口，直接連通後台審查工作台，不產生重複進件。
   - **防自動化偏誤 (Automation Bias)**：後台專員執行核准、補件或否決時，強制要求輸入實質理由，並留存於不可篡改之 Audit Log。
   - **非功能與倫理防護**：繳款具備防重複點擊扣款鎖定，原型設定 0 罰息，絕不騷擾通訊錄或親友。

## 🚀 快速啟動與操作指南

本網站為純靜態現代 Web 應用（HTML5 + Tailwind CSS + Vanilla ES6 JS），相容所有主流瀏覽器，零依賴即可啟動：

### 方法一：直接點擊開啟
進入資料夾 `c:\_HCI\`，使用滑鼠雙擊 `index.html`，即可在 Edge、Chrome 或 Firefox 中直接執行。

### 方法二：透過本機 Python HTTP 伺服器啟動
開啟 PowerShell 或 Terminal，依序輸入：
```powershell
cd c:\_HCI
python -m http.server 8000
```
開啟瀏覽器訪問：[http://localhost:8000](http://localhost:8000)

## 🎯 課堂 6 大測試情境快捷切換 (Scenario Quick Launcher)

在網站上方功能列的下拉選單中，可隨時一鍵載入作業所設計的情境腳本：

1. **情境一：林先生 50,000元 AI順利核貸與方案C (ML001)**
   - 演示正常申請、AI 自動核貸、三方案對照與方案 C 選定、電子手寫簽名開案。
2. **情境二：OCR 收入誤讀 (28k->18k) 修正與重算 (SIM-W02)**
   - 演示影像辨識誤讀造成可用餘額為負，透過「更正資料」按鈕修正為 28,000 元後重啟試算。
3. **情境三：超過10萬 (120,000元) 分流至人工審核 (ML002)**
   - 演示超額分流，前台清楚顯示「人工審核中，尚未核准」，並可一鍵切換至後台由陳專員審批。
4. **情境四：80,000元 無法核貸與人工覆核申訴 (ML004)**
   - 演示現金流不足無法核貸，透過「申請人工覆核」填寫異議說明並送至後台專員。
5. **情境五：資料缺漏待補件 (30,000元) (ML003)**
   - 演示收入欄位缺失，系統堅持不自動補零值，發送補件指引。
6. **情境六：還款與清償結案展示 (ML005 -> ML006)**
   - 演示履約中案件線上繳款、防重複扣款保護，以及全額清償後頒發數位證明與結案狀態。
